# noktostudio.com

Static website of Nokto Studio, SEO agency for business owners (SK + CZ + EN).
Live at https://noktostudio.com via GitHub Pages (CNAME file).

## Design

Google-colored light theme. Brand palette:

| Color | Hex | Use |
|---|---|---|
| Blue | `#4285F4` / `#1A73E8` | primary, logo letter N, buttons, links |
| Red | `#EA4335` | logo letter o, accents |
| Yellow | `#FBBC04` | logo letter k, accents |
| Green | `#34A853` | logo letter t, success states |

Pricing model everywhere on the site: 12 EUR per hour, transparent, no retainers,
free call + free audit as the entry offer.

## Structure

```
index.html            SK homepage (the root IS the Slovak site)
sk/                   SK pages (sluzby, cennik, jak-pracujeme, pripady, faq, blog, ...)
sk/index.html         redirect stub to /
cz/                   Czech version (mirror of the SK service tree)
en/                   English version (secondary market)
en/projects/          legacy project demo pages (own legacy CSS, kept as-is)
assets/               CSS (Google theme), JS (nav, forms, cookie banner, analytics), images
sitemap.xml           generated, includes hreflang alternates for the 3 homepages
robots.txt            allows all crawlers incl. AI bots (GPTBot, PerplexityBot, ClaudeBot, ...)
build/                Python content modules (SK/CZ/EN pages)
build_site.py         the site builder
```

## Editing and rebuilding

The pages are generated by `build_site.py` from the content modules in `build/`.
Edit copy in `build/pages_*.py`, then rebuild:

```bash
python3 build_site.py
```

This rewrites all HTML, sitemap.xml and robots.txt. The output is plain static
HTML, so the live site has no Python dependency.

- `build/engine.py` - layout, nav, footer, reusable components (pricing cards, steps, FAQ)
- `build/pages_sk.py` + `build/pages_sk2.py` - Slovak pages
- `build/pages_cz.py` - Czech pages
- `build/pages_en.py` - English pages

## SEO notes

- hreflang alternates are emitted only on the three homepages (SK root, /cz/, /en/);
  deep pages have no 1:1 translations, so per-page alternates would claim false pairs.
- Schema: Organization + WebSite sitewide, Service on each service page (hourly offer),
  FAQPage on home/faq/cennik, BreadcrumbList via visible breadcrumbs.
- Language toggle falls back to the market home when an equivalent page does not exist.
- Keyword research behind the page tree lives outside the repo in
  `~/Sync/projects/nokto/noktostudio/research/` (AKW workbook: akw_noktostudio.xlsx).
